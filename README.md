# Employee Management System

A full-stack Employee Management System built using Angular, Spring Boot, and MySQL.

## 🚀 Tech Stack
- Angular
- Spring Boot
- MySQL
- Bootstrap

## ✨ Features
- Add Employee
- Update Employee
- Delete Employee
- View Employees
- REST API Integration
- Responsive UI
